## 📦 Open Source

Libraries I build and maintain — published on NuGet, each with a live interactive demo.

### [Deja](https://github.com/lisihasaj/Deja) · [![NuGet](https://img.shields.io/nuget/v/Deja.svg?label=NuGet)](https://www.nuget.org/packages/Deja/) [![Docs](https://img.shields.io/badge/docs-live%20demos-blue)](https://lisihasaj.github.io/Deja/)

**Data fetching, mutation and caching primitives for Blazor** — WebAssembly and Server.
Queries, mutations and a shared keyed cache in idiomatic C#, in the spirit of React Query.
Extracted from a production Blazor application. Zero third-party dependencies, targets .NET 8 / 9 / 10.

### [ToastRack](https://github.com/lisihasaj/ToastRack) · [![NuGet](https://img.shields.io/nuget/v/ToastRack.svg?label=NuGet)](https://www.nuget.org/packages/ToastRack) [![Demo](https://img.shields.io/badge/demo-interactive-blue)](https://lisihasaj.github.io/ToastRack/)

**A lightweight, dependency-free toast notification library for Blazor** — WebAssembly and Server.
Loading toasts with determinate progress, action buttons, six stacking positions with boundary
anchoring, full CSS-variable theming and accessibility built in. Targets .NET 8 / 9 / 10.

## 🏢 Enterprise & Client Work

Production systems I've engineered in cooperation with companies — the source lives in
private repositories, so here is what they are rather than the code itself.

### EBZ Project Cockpit — EBZ Group 🇩🇪

Enterprise project- and resource-management platform for **EBZ Group**, an education and
services group for the German housing and real-estate industry.

- Modular **Blazor WebAssembly** solution on the latest **.NET**, developed in a distributed team
- Real-time collaboration with **SignalR**, background processing with **Hangfire**
- Project planning, resource planning and reporting modules on **Entity Framework / SQL**
- **GitLab CI/CD** pipelines with **SonarQube** quality gates and automated test suites

### GeoCAD Platform — GeoCAD 🇽🇰

Full-stack web platform for **GeoCAD**, a geodesy and surveying company.

- **Python / FastAPI** REST backend with **PostgreSQL**
- **React** public site (internationalized) and admin interface
- Multi-service **Docker** deployment behind **nginx**, single-source environment configuration

### Modular CMS *(in development)*

A modular, self-hosted CMS of my own design — **FastAPI + PostgreSQL** core with separate
admin and web services, built to power client sites from one deployable stack.
